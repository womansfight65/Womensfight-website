# Women's Fight — GitHub Pages site

A static landing page mirroring the Women's Fight home page design, hosted
free on GitHub Pages at https://womansfight65.github.io/my-website/

## Structure

- `index.html` - the home page
- `style.css` - the same styling as the WordPress theme (`wordpress-theme/womens-fight/style.css`)
- `script.js` - mobile menu toggle
- `assets/img/` - logo files

## Note

This page links out to the live WordPress site
(https://lsitagency.moriomfashionmh.com/) for everything beyond the
homepage (services, contact, AI Agent, etc.), since GitHub Pages only
serves static files and can't run the WordPress theme in
`wordpress-theme/womens-fight/`.

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static file server.
